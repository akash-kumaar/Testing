# ExpenseIQ

ExpenseIQ is a simple expense tracking web application built using Flask and SQLite. It allows users to record their expenses, organize them into categories, and keep track of their spending habits.

## Features

* Add and delete expenses
* Categorize expenses
* View expense history
* Essential and non-essential expense classification
* SQLite database storage
* Simple and lightweight design

## 🚧 Project Status

Currently working on improving the project and adding new features such as:

* Budget tracking
* Spending analytics
* Charts and visualizations
* AI-powered expense suggestions
* Monthly expense reports

## Tech Stack

* Python
* Flask
* SQLite
* HTML

## Running the Project

1. Clone the repository

```bash
git clone https://github.com/yourusername/ExpenseIQ.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
python app.py
```

4. Open your browser and visit:

```text
http://127.0.0.1:5000
```
